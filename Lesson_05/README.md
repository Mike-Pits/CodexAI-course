# Проекты занятия 5

В рабочей папке сохранены две независимые реализации каждого задания.

- `vsellm/lite` и `vsellm/pro` используют внешний OpenAI-совместимый API VseLLM. Конфигурация и ключи хранятся только внутри соответствующих `.env`.
- `local/lite` и `local/pro` используют локальный Ollama с моделями `qwen3:8b` и `bge-m3`. Документы и вопросы не покидают компьютер.

Варианты не импортируют код или индексы друг друга. Для каждой реализации создаётся собственное виртуальное окружение и собственный файл `data/index.json`.

Для первичной установки Ollama и локальных моделей выполните:

```bash
bash local/setup_ollama.sh
```
