# Отчёт по домашнему заданию 09

Выполнено 19 ноября 2026 года. Исходные задания сохранены без изменений. Ранее выполненная работа не использовалась.

## Lite

Создан локальный браузерный чат в `lite/`. Удалённый сервер https://weather.chukai.io/mcp проверен реальной MCP-инициализацией: HTTP 200. Приложение загружает инструменты через `tools/list`, передаёт схемы LLM и выполняет выбранные `tools/call` через официальный MCP SDK. Своего погодного MCP-сервера нет.

Проверены последовательно два сообщения в одной истории: «Какая сейчас погода в Екатеринбурге?» и «А в Казани?». В обоих случаях выполнены новые MCP-геокодирование и погодный запрос. В сохранённом прогоне Екатеринбург: −1,8 °C, пасмурно, ветер 1,63 м/с; Казань: +1,4 °C, сильная морось, ветер 4,47 м/с. Это фактические ответы сервиса на момент проверки, не актуальная сводка для будущего чтения.

Проверена недоступность сервера: вместо подстановки значений показана ошибка. Журнал с вопросами, ответами, параметрами и результатами — `lite/evidence/verification.json`. Проверка синтаксиса: `cd lite && npm run check`.

Локальная `qwen3:8b` в ранних прогонах брала координаты из памяти и неверно описывала погодный код. Поэтому прогноз разрешён только для координат, полученных через MCP; кириллица геокодируется с `language=ru`; итоговая сводка собирается из фактических полей ответа, с точной расшифровкой WMO-кода. Два города в одном сообщении не поддерживаются: спрашивайте последовательно.

## Pro

Использован готовый Excel MCP Server 2.3.2: https://github.com/haris-musa/excel-mcp-server . Выбран за поддержку чтения/записи ячеек, локального stdio и работы без Microsoft Excel. MCP-процесс ограничен папкой `pro/data`. Подробное описание подключения, инструментов и запуска — `pro/README.md`.

Все операции с данными книги выполняет готовый MCP-сервер: `create_workbook`, `read_range`, `write_range`. Оформление также сделано через MCP: `format_range`, `set_sheet_layout`. Приложение не использует прямое чтение или запись через openpyxl/pandas.

Проверены с настоящей LLM и MCP:

- Исходные строки 101–103 и четыре заданных столбца на листе «Заявки».
- Добавление Анны Смирновой: перед записью прочитаны ID, присвоен 104, установлен «Новый», результат проверен повторным чтением.
- Предложение смены статуса: показаны ID/клиент/старый и новый статусы; до подтверждения вызовов записи нет.
- Подтверждение: изменена только D5, затем сравнена вся таблица; остальные данные сохранены.
- Фильтр «В работе»: две заявки, Мария Соколова и Анна Смирнова, с количеством.
- Заявка 999: не найдена, без вызовов записи.
- Неполная заявка Дмитрия: уточнение проблемы, без вызовов записи.
- Повторное чтение после ошибочных/неполных команд: данные не изменились.

Финальный повторный прогон выполнен на отдельной автоматически созданной тестовой книге. `pro/data/requests.xlsx` содержит итоговый пример из четырёх заявок, включая Анну «В работе». Журналы: `pro/evidence/verification.json` и `.log`. Проверка синтаксиса: `cd pro && npm run check`.

В браузере дополнительно проверены загрузка таблицы через MCP, предложение изменения №104 и кнопка отмены: статус остался «В работе». Скриншот интерфейса: `pro/evidence/browser-preview.jpg`. Книга визуально проверена рендером LibreOffice: все четыре столбца и четыре заявки читаемы, помещаются на одной странице; изображение — `pro/evidence/workbook-preview.png`. LibreOffice использовался только для визуальной проверки, не для операций приложения с данными.

Независимый агент провёл обзор исходников по навыку requesting-code-review; существенных ошибок в обязательных сценариях не найдено. После этого добавлена нормализация регистра/пробелов статусов для локальной LLM и повторно пройдены обязательные сценарии.

## Запуск и ограничения

Проверки выполнялись с уже установленной Ollama `qwen3:8b`, без платного API. Для API-варианта в примерах настроена `gpt-4.1-mini`; этот вариант без пользовательского API-ключа не запускался. Наличие успешного прогона небольшой локальной модели не гарантирует правильный выбор функции для любой формулировки; параметры и изменения дополнительно проверяются приложением.

Приложения слушают только 127.0.0.1. Для Lite нужен интернет; для Pro — установленный MCP-сервер и работающая LLM. Одна вкладка хранит историю до перезагрузки. Не запускайте несколько экземпляров Pro над одной книгой и не редактируйте книгу вручную одновременно с записью приложения.

ZIP включает исходники, зафиксированные зависимости, инструкции, пример Excel и реальные журналы. Секреты `.env`, виртуальное окружение, node_modules и временные тестовые книги в ZIP не включены.
