# Lite: погода через удалённый MCP

Локальный браузерный чат: пользователь → LLM → MCP SDK → https://weather.chukai.io/mcp → Open-Meteo → ответ на русском.
Собственный погодный MCP-сервер не создаётся. Список и JSON Schema инструментов загружаются через `tools/list`; модель сама выбирает инструменты и параметры. История диалога хранится на сервере отдельно для каждой вкладки. Каждый `tools/call` выводится в журнал интерфейса и консоли вместе с параметрами и результатом. Прямых запросов приложения к Open-Meteo нет.

## Запуск

Требуются Node.js 22+, интернет и LLM с поддержкой Chat Completions function calling.

```bash
cd lite
npm ci
cp .env.example .env
# Укажите параметры LLM в .env
npm start
```

Откройте http://127.0.0.1:3000. Для уже установленной Ollama:

```dotenv
LLM_BASE_URL=http://127.0.0.1:11434/v1
LLM_API_KEY=ollama
LLM_MODEL=qwen3:8b
```

Если модели ещё нет: установите Ollama, выполните `ollama pull qwen3:8b`, запустите Ollama. Для OpenAI можно использовать настройки из `.env.example` с собственным ключом; расходы зависят от сервиса. `.env` не включается в архив.

## Проверка

```bash
npm run check
node check-mcp.mjs
node verify.mjs
```

`verify.mjs` запускает настоящую LLM, последовательно задаёт «Какая сейчас погода в Екатеринбурге?» и «А в Казани?», требует успешный погодный MCP-вызов в каждом ответе, затем проверяет недоступный endpoint. Журналы сохраняются в `evidence/`. Проверка потребляет ресурсы выбранной LLM.

В браузере повторите те же вопросы и раскройте журнал MCP. При отсутствии сервера/ключа приложение показывает ошибку, без подставных погодных значений. Текущая погода меняется; сохранённые журналы — данные на момент проверки, а не прогноз для будущего запуска.

Реализация function calling сверена с https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create . Модели, требующие исключительно Responses API, для этого приложения не подходят.

Сводка температуры, условий и ветра собирается приложением из фактических полей MCP-ответа: LLM выбирает город и инструменты, а числовые данные и расшифровка WMO-кода не проходят свободный пересказ. Координаты прогноза проверяются на совпадение с результатом MCP-геокодирования. Для кириллицы явно задаётся язык `ru`. В текущей учебной версии один запрос возвращает погоду одного города; несколько городов спрашивайте последовательно.
