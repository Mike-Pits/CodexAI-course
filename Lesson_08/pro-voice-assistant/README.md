# Голосовой помощник для проверки расписания

Учебное браузерное приложение принимает голосовую или текстовую просьбу, проверяет встроенное расписание и отвечает текстом и голосом. Приложение не оформляет запись.

## Запуск

1. Откройте терминал в папке проекта.
2. Перейдите в /pro-voice-assistant и запустите локальный сервер:

   ```bash
   python3 -m http.server 4173
   ```

3. Откройте `http://localhost:4173` в Chrome или Edge.
4. Нажмите «Начать разговор», затем «Говорить» и разрешите доступ к микрофону.

Если распознавание речи в браузере недоступно, используйте текстовое поле в нижней части диалога. Синтез речи и распознавание зависят от поддержки Web Speech API браузером и системой.

## Сценарии проверки

- «Можно завтра после шести?» — помощник предложит 18:30 и сообщит, что 19:00 занято.
- «Можно завтра в семь?» — помощник сообщит, что 19:00 занято, и предложит 18:30.
- «Нет, лучше послезавтра» — помощник сообщит, что данных нет.
- «Сымитировать сбой расписания» — интерфейс покажет понятную ошибку и предложит повторить запрос или начать новую сессию.

Чтобы проверить перебивание, нажмите «Говорить», пока помощник воспроизводит ответ. Текущий звук и ещё не показанные части ответа будут отменены.

## Файлы

- `index.html` — разметка интерфейса.
- `styles.css` — адаптивное оформление и состояния.
- `app.js` — голосовой ввод, проверка расписания, потоковый текст, TTS, ошибки и управление сессией.
- `Описание реализации.md` — краткое описание для сдачи.
