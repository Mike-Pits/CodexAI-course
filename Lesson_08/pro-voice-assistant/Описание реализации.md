# Описание голосового помощника

## Архитектура

В приложении используется каскадная архитектура: распознавание речи STT → обработка просьбы AI агентом → проверка учебного расписания → синтез речи TTS. Расписание хранится локально в логике приложения: завтра в 18:30 свободно, завтра в 19:00 занято, на послезавтра данных нет.

## Инструменты

Голосовой ввод работает через браузерный Web Speech API `SpeechRecognition`, а ответ озвучивается через `SpeechSynthesis`. Правила учебного AI агента извлекают дату и время из реплики и запрашивают встроенное расписание. Внешний API и секретные ключи не используются.

## Потоковая передача

Реализована потоковая передача текста: слова ответа появляются в диалоге постепенно по мере формирования сообщения. После завершения текстового потока браузер воспроизводит голосовой ответ.

## Состояния и ошибки

Интерфейс показывает этапы «слушает», «проверяет расписание», «воспроизводит ответ», «разговор завершён» и «возникла ошибка». При ошибке пользователь может повторить последний запрос или начать новую сессию. Начало новой сессии очищает историю, отменяет незавершённые таймеры и останавливает старый звук, поэтому ответ предыдущей сессии не воспроизводится.

## Дополнительное усложнение

Реализовано перебивание. Если пользователь нажимает «Говорить» во время голосового ответа, приложение останавливает синтез речи, удаляет запланированные части текущего текстового потока и начинает обработку новой реплики.
