# Работа с проектом «Точка опоры»

## Назначение и границы

Учебное задание Light к уроку 01 курса Codex_AI: русскоязычный веб-администратор вымышленного сервиса психологической поддержки. Стек: FastAPI и HTML/CSS/JavaScript. Общение с пользователем — на русском.

Бот сообщает услуги, цены, расписание и порядок обращения по данным проекта. Сохраняй обозначение учебного проекта и демонстрационных контактов. Реальной записи, оплаты, регистрации и терапии здесь нет. Бот не ставит диагнозы; для непосредственной опасности предусмотрена рекомендация срочной помощи.

История чата хранится только в памяти страницы. Серверная база предназначена для квот, а не переписки. Сохраняй ограничения запросов, проверку входных данных и уведомление о передаче сообщений провайдеру LLM.

## Где искать подробности

- Перед запуском или изменением настроек прочитай `README.md` и `.env.example`.
- Перед изменением поведения бота прочитай `app/business.json` и `app/prompt.txt`; сведения об услугах меняй в файле данных.
- При проверке задания используй `CHECKS.md`. Mock-ответы не подтверждают работу настоящей модели.
- Перед публикацией, изменением Docker, DNS или HTTPS прочитай `DEPLOY.md`, `compose.yaml` и `Caddyfile`.

## Ключи и провайдер

Секреты находятся только в локальном `.env`. Не выводи ключи, полное содержимое `.env`, заголовки авторизации и пользовательскую переписку в чат или журналы. Для диагностики выводи HTTP-статус, класс сетевой ошибки и безопасные параметры.

Используй настройки `LLM_*` для стороннего провайдера. Старый ключ OpenAI нельзя автоматически подставлять для другого адреса API. Проверки генерации отправляют реальные, потенциально платные запросы; выполняй их только в рамках согласованного тестирования.

## Запуск и проверка

Команды выполняются из этой папки:

```bash
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000 --no-proxy-headers --no-access-log
.venv/bin/python -m pytest -q
.venv/bin/python scripts/check_llm.py --probe
python3 scripts/package.py
```

После изменения `.env` перезапусти именно процесс этого проекта. Проверь `/api/health` и, при изменениях интеграции LLM, ответ через `/api/chat`. Успешный список моделей подтверждает авторизацию, но не генерацию.

Архив для сдачи создавай через `scripts/package.py`: он использует явный список файлов и исключает секреты, базу квот, SSH-сокеты и виртуальное окружение. При добавлении нужной документации обновляй список упаковки.

## Состояние на 29 сентября 2026

Локально проверена генерация через VseLLM с моделью `openai/gpt-5.6-luna`, включён `CHAT_MODE=llm`. Ответ через `/api/chat` успешен; 41 автоматический тест прошёл. Перед новой работой сверяй фактическое состояние, не считай эти результаты постоянными.

Сеть давала перемежающиеся `ConnectTimeout` даже по IPv4. Причина в VPN не доказана. В HTTP-клиентах настроены два повтора установления соединения; отправленные запросы генерации автоматически не повторяются. Принудительный IPv4 не включён.

Следующий согласованный этап — публикация на VPS и домен с HTTPS. Домен пока не сообщён. На VPS сохраняем Ubuntu 20.04; перед установкой проверяем совместимость и обновления безопасности. Локальная система — Ubuntu 24.04.

На VPS порт 443 занят существующим сервисом; для проекта выбран HTTPS на 8443, порт 80 нужен для HTTP-проверки сертификата. Сохраняй существующие VPN-сервисы и SSH-доступ. Перед развёртыванием повторно проверь занятые порты и состояние сервера. Если безопасное развёртывание требует изменения согласованной системы, обсуди препятствие с пользователем до установки.
