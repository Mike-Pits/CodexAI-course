# Требования к AI анализатору видеовстреч

## Назначение

Один пользователь добавляет короткую видеозапись встречи вручную или по прямой облачной ссылке. Приложение автоматически распознаёт речь, создаёт структурированный конспект и сохраняет его для последующего просмотра.

## Функциональные требования

| ID | Требование | Проверяемый результат |
|---|---|---|
| FR-01 | Ручная загрузка WebM и MP4 | Файл до 500 МБ и 5 минут проходит проверку видео- и аудиодорожки |
| FR-02 | Автоматический запуск | После загрузки создаётся один pipeline без отдельной кнопки анализа |
| FR-03 | Распознавание речи | Реальное содержимое видео преобразуется в текст |
| FR-04 | AI-анализ | Формируются резюме, темы, решения, задачи и открытые вопросы |
| FR-05 | Статусы | Видны этапы «Загружен», «Распознавание речи», «AI-анализ», «Готово» и «Ошибка» |
| FR-06 | Сохранение | Видеофайл, текст, результат и этап доступны после обновления страницы |
| FR-07 | Аналитическая панель | Видны счётчики, последние встречи, источник, дата, резюме и подробности |
| FR-08 | Облачный импорт | Публичная прямая HTTPS-ссылка загружает WebM или MP4 |
| FR-09 | Ограничения облака | Авторизация и непрямые ссылки дают понятную ошибку и предлагают ручную загрузку |
| FR-10 | Единая обработка | Ручной и облачный источники используют один pipeline |
| FR-11 | Дедупликация | Повторная нормализованная ссылка открывает сохранённую встречу |
| FR-12 | Безопасность URL | Локальные адреса, приватные IP, небезопасные схемы и нестандартные порты отклоняются |

## Ограничения

- API облачного провайдера и OAuth не требуются.
- Поддерживается прямое скачивание без авторизации.
- Видео длиннее 5 минут не входит в текущий объём.
- Очередь использует один устойчивый локальный worker.
- Модели и данные работают локально, как в `Lesson_02`.
- Публичный Vercel deployment требует внешних AI, БД, object storage и фонового worker.

## Данные

SQLite хранит встречи, файлы, задания и результаты. Для видеовстреч сохраняются источник, нормализованная облачная ссылка и SHA-256. Файлы находятся в `data/files/<meeting-id>/`.
