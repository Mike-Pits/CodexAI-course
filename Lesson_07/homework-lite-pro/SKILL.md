# Lite and Pro Homework

## Required clarification

Before reading the assignments or starting any work, ask the user: "Are these assignments based on previously completed work? If so, which work should I use as the starting point?"

Stop and wait for the answer. Ask this question on every new skill invocation, even when a dependency on previous work seems unlikely.

If the answer is yes, locate or request the identified materials and treat them as the baseline. Resolve any ambiguity about the baseline before making changes. If the answer is no, start from the current project files.

## Workflow

1. Find exactly one Lite assignment and one Pro assignment in the project directory by matching their filename markers case-insensitively. Ask the user to choose if a file is missing or multiple candidates match.
2. Read both assignments and identify every required deliverable, constraint, and completion criterion. Use the appropriate available skill for document, spreadsheet, presentation, or PDF formats.
3. Complete Lite in full. Create the required artifacts in the project directory, verify them, and proceed to Pro only after Lite meets all completion criteria.
4. Complete Pro in full, using the Lite result or previous work when required by the assignment. Create and verify every required artifact.
5. Report Lite and Pro separately, including completed work, created or modified files, and verification performed. State any remaining blockers or assumptions.

Preserve the original assignment files unless an assignment explicitly requires editing them. Keep existing user materials and results intact unless the user explicitly authorizes replacement or deletion.
