# План реализации

## Lite

1. Перенести приложение `Lesson_02` без пользовательских данных, моделей и окружения.
2. Добавить в БД источник записи и контрольную сумму.
3. Реализовать проверку WebM и MP4.
4. Создать единый pipeline распознавания и анализа.
5. Добавить панель «Аналитика встреч», загрузку видео, статусы и карточки.
6. Проверить сохранение результата и обработку ошибок.

## Pro

1. Добавить безопасное скачивание по прямой HTTPS-ссылке.
2. Повторно использовать pipeline Lite.
3. Нормализовать ссылку и предотвращать повторную обработку.
4. Отобразить источник записи и запасной сценарий ручной загрузки.
5. Проверить опасные URL, повторный импорт и визуальный результат.

## Внешняя публикация

GitHub и Vercel выполняются после выбора аккаунтов и инфраструктуры. Для полной функциональности на Vercel нужны постоянные БД и object storage, AI API или GPU worker и внешняя очередь задач.
