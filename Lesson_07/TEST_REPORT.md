# Отчёт о проверке

Дата проверки: 4 ноября 2026 года.

## Пройдено

- Python-модули компилируются через `py_compile`.
- JavaScript проходит `node --check`.
- Lite smoke: видеозапись сохраняется, получает статус «Загружен», проходит распознавание и AI-анализ, результат сохраняется как `current`, статус становится «Готово».
- Pro smoke: HTTPS-ссылка нормализуется, облачный файл создаёт встречу с источником `cloud`, повторная ссылка возвращает существующую встречу и не скачивается второй раз.
- Отклоняются HTTP, URL с учётными данными и `file://`.
- Интерфейс проверен в браузере на ширине 1440 px: панель, загрузка, облачная форма, карточка видео, расшифровка, статус и сохранённый результат читаемы без наложений.
- Созданы полноразмерные скриншоты панели и результата.

## Ограничения проверки

- Полный набор унаследованных тестов FastAPI не завершился в ограниченной агентской среде: `TestClient` зависает при первом запросе. Такое ограничение было зафиксировано и в исходном `Lesson_02`.
- Реальные модели не копировались в `Lesson_07`, потому что они занимают много места. Для запуска используются штатные `scripts/setup.sh` и `scripts/download-models.sh`.
- Реальный импорт из пользовательского облачного аккаунта не выполнялся: не предоставлена публичная ссылка на учебную запись.
- Production deployment Vercel ещё не создан: Vercel CLI требует интерактивный вход пользователя и подключение ресурсов аккаунта.

## Демонстрационные данные

Визуальная проверка использует реальную учебную WebM-запись и соответствующий сохранённый AI-результат из `Lesson_02`. Эти данные размещались только во временной папке и не добавлены в проект.

## Раздельные deployment-профили

- локальный профиль: `MEETINGS_RUNTIME=local`, SQLite-схема v2 и импорт приложения проверены без облачных переменных;
- Vercel-профиль: `MEETINGS_RUNTIME=vercel`, регистрация приватного Blob, создание pipeline job и чтение результата проверены через отдельную libSQL-БД;
- тот же cloud smoke-тест пройден на Python 3.12 — версии, зафиксированной в `.python-version` для Vercel;
- импорты `@vercel/blob`, AI SDK, `@libsql/client` и Zod проверены на Node.js 22;
- `npm audit --omit=dev` после фиксации `package-lock.json`: 0 известных уязвимостей;
- `bash -n scripts/vercel-setup.sh`, Python `py_compile`, Node `--check` и `git diff --check` проходят.

Локальная команда `vercel build` дошла до обязательного шага аутентификации и остановилась с `login_required`. Это ожидаемый ручной этап: вход, подключение Blob/Turso и Preview deployment выполняет пользователь через `scripts/vercel-setup.sh`.
