# AI куратор онлайн школы

Решение заданий Lite и Pro занятия 4. Обе версии консультируют по курсу «Практика Python», учитывают контекст разговора, сохраняют полезные сведения и разделяют права клиента и администратора. Lite использует JSON; Pro хранит пользователей, память и историю диалогов в SQLite.

## Запуск Pro

```bash
cd /home/mike-pi/Documents/coding/NU/Courses/CodexAI-course/Lesson_04
bash scripts/run_pro.sh
```

Откройте <http://127.0.0.1:8766>. База `data/pro.sqlite3` создаётся при первом запуске. Клиент видит историю собственных диалогов, может продолжать любой из них, менять и удалять сохранённые предпочтения. Администратор управляет долговременной памятью пользователей.

## Таблицы Pro

| Таблица | Назначение | Основные связи |
|---|---|---|
| `users` | Учётные записи, роли и хеши паролей | Родитель для памяти и диалогов |
| `memories` | Отдельные долговременные сведения | `user_id → users.id`, уникальная пара пользователя и ключа |
| `dialogs` | Диалоги клиента и их заголовки | `user_id → users.id` |
| `messages` | Реплики пользователя и куратора | `dialog_id → dialogs.id`, удаляются вместе с диалогом |

SQLite включает внешние ключи и индексы по пользователю, времени обновления диалога и порядку сообщений. Каждый метод открывает короткое соединение, фиксирует или откатывает транзакцию и гарантированно закрывает соединение.

## Запуск Lite

Требуется Python 3.10 или новее. Внешние библиотеки не нужны.

```bash
cd /home/mike-pi/Documents/coding/NU/Courses/CodexAI-course/Lesson_04
bash scripts/run.sh
```

Откройте <http://127.0.0.1:8765>. При первом запуске автоматически создаётся `data/store.json` с тестовыми пользователями. В Pro используются те же демонстрационные входы:

| Роль | Логин | Пароль |
|---|---|---|
| Клиент | `anna` | `anna-demo` |
| Клиент | `boris` | `boris-demo` |
| Администратор | `admin` | `admin-demo` |

Пароли сохраняются в JSON только в виде PBKDF2-хешей с индивидуальной солью. Демо-пароли предназначены исключительно для локального учебного запуска.

## Как устроена память Lite

- Краткосрочная память хранится в серверной сессии. Агент получает до 21 пары реплик текущего диалога. Кнопка «Новый диалог», выход или перезапуск сервера очищают этот контекст.
- Долгосрочная память находится в `data/store.json`. Из явных фраз агент извлекает имя, цель, бюджет, предпочитаемый формат, темп и опыт. Клиент может просматривать, исправлять и удалять только собственные сведения.
- Администратор видит профили всех пользователей и может их исправлять. Клиентские запросы к административным адресам получают HTTP 403.
- Запись JSON выполняется через временный файл с атомарной заменой, поэтому незавершённая запись не должна оставлять частично записанный документ.

История текущего чата намеренно не сохраняется в JSON: по условию Lite долгосрочно хранятся полезные сведения, а не полная переписка. SQL не используется — это относится к заданию Pro.

## AI режим обеих версий

Без ключа приложение работает в воспроизводимом локальном демо-режиме. Он показывает механику памяти, персонализацию, продуктовые ограничения и права доступа. Для ответов внешней модели создайте `.env` из примера и заполните параметры OpenAI-совместимого Chat Completions API:

```bash
cp .env.example .env
```

Ключ остаётся на сервере и не отправляется в браузер. Модель получает информацию только текущего клиента, контекст текущего диалога и фиксированные сведения о курсе. Условия скидок, рассрочки и возврата в исходных данных не заданы; агенту запрещено их придумывать.

## Проверка

```bash
python3 -m unittest discover -s tests -v
node --check static/app.js
```

Общий прогон выполняет 12 тестов: 6 для Lite и 6 для Pro. Pro отдельно проверяет связи SQL, сохранение сообщений, изменение и удаление памяти. Подробности Lite находятся в `TEST_REPORT.md`, результаты Pro — в `PRO_TEST_REPORT.md`. Для обоих вариантов подготовлены Word-отчёты.

## Границы реализации

Это учебное локальное приложение. В обеих версиях авторизационные сессии хранятся в оперативной памяти и не рассчитаны на несколько процессов. HTTPS, восстановление паролей, журнал аудита и защита от перебора не реализованы. Pro сохраняет историю диалогов, но отправляет модели не более 42 последних сообщений выбранного диалога.
